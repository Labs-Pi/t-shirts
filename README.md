# Loose Thread — t-shirts

Two-page three.js site:

- **Rack** (`index.html`) — tees hanging side-on on a rail; hover turns one to face you, neighbours slide apart, cursor movement blows a light breeze through the fabric, click to see the back.
- **Tee** (`tee.html`) — a single tee with colour and print options; drag to rotate.

No build step: open `index.html` or serve the folder statically.
